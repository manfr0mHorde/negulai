# Qalta — личный бюджет (PWA)

Бесплатное статическое приложение для iPhone. Без React, npm, базы данных на сервере, собственного домена и Apple Developer Account.

## Что есть в первой версии
- План месячных доходов: зарплата, стипендия и дополнительный доход.
- Стартовый баланс и фактические доходы/траты отдельно от плана.
- Категории с месячными лимитами, фиксированными планами и целями.
- Конверты «Сбережения» и «Акции» (отложенные деньги исключаются из свободного баланса).
- Рассрочки, остаток задолженности и учёт платежей.
- Дни до следующей зарплаты и шутливые подсказки.
- История, удаление ошибочных операций, резервная копия JSON и восстановление.
- Офлайн-режим после первоначальной загрузки и установки.

## Разместить бесплатно на GitHub Pages
1. Создай публичный репозиторий на GitHub, например `ne-gulyai`.
2. Загрузи **содержимое** папки `kopilka-pwa` в корень репозитория (index.html, app.js, style.css, sw.js, manifest.webmanifest и папку icons).
3. Репозиторий → **Settings → Pages** → **Build and deployment → Deploy from a branch** → ветка `main`, каталог `/(root)` → **Save**.
4. Адрес будет `https://ТВОЙ-ЛОГИН.github.io/ne-gulyai/`.
5. На iPhone открой адрес в Safari → «Поделиться» → «На экран Домой» → «Добавить» (при наличии переключателя включи «Открывать как веб-приложение»).

## Локальная проверка на компьютере
В папке проекта: `python3 -m http.server 8080`, затем открой `http://localhost:8080`. Для установки на iPhone нужен HTTPS, который бесплатно даст GitHub Pages.

## Важно
- История хранится **локально в localStorage конкретного приложения/браузера**. Это не банковская интеграция и не облачная синхронизация.
- Не указывай пароли от банков; приложение их не требует.
- Регулярно делай **Настройки → Экспорт резервной копии** и сохраняй JSON в iCloud Drive/«Файлы».
- Плановая зарплата не прибавляется к балансу автоматически: внеси фактическое поступление кнопкой `+`.
- Ежемесячный план категорий повторяется, а траты считаются по календарному месяцу; остатки лимитов на следующий месяц не переносятся.
- Сбережения/акции — виртуальные конверты, не реальные банковские переводы; сам перевод в банк выполняется отдельно.
- Изменение стартового баланса после начала учёта меняет итоговый баланс. Не вводи новый текущий баланс поверх уже записанных операций.
- Статическое приложение не может само получать операции Kaspi/Halyk; они вводятся вручную.
- При следующих публикациях обновляй версию CACHE в sw.js (например, `negulyai-static-v3`), чтобы PWA обновилась на iPhone.
- Теперь можно возвращать деньги из конвертов сбережений и акций через кнопку «Вернуть в баланс».
- При удалении рассрочки её платежи в истории сохраняются. Поэтому перед удалением проверь и сохрани резервную копию.

## Настраиваемые конверты (v3)
- По умолчанию: продукты для дома, коммунальные услуги, тариф и проезд.
- Нажми «Своя категория» для создания расхода с месячным лимитом или накопления с общей целью.
- Сумма накоплений показывает остаток цели и переносится между месяцами. Скрытые категории остаются в истории.
- Категории предыдущей версии с установленными суммами или операциями сохраняются при обновлении; записи «Такси» переходят в «Проезд».
- День зарплаты теперь выбирается датой в календаре, далее повторяется ежемесячно.
- Двуязычные финансовые мысли обновляются ежедневно или по кнопке ↻.
