# Secret Garden Astana — демонстрационная витрина

Неофициальный прототип цветочного магазина для GitHub Pages. Два режима: витрина клиента и кабинет флориста.

Покупатель: каталог, корзина, оформление с адресом, временем и телефоном для удаленного счета Kaspi, подготовка WhatsApp-заявки.
Продавец: добавить / изменить / копировать букет, отметить как «Продан», загрузить фото с телефона, статистика демо-заявок.

## Принципиальные ограничения
- Данные сохраняются **только в localStorage этого браузера**: другой телефон НЕ увидит изменения каталога. Это демо, не коммерческий продукт.
- Статистика локальная и не подтверждает реальные продажи. Тестовые заказы не являются оплаченными.
- При оформлении заказа персональные данные не сохраняются в журнале. Внешних запросов с личными данными нет, пока пользователь сам не откроет WhatsApp.
- WhatsApp реального магазина отключен по умолчанию. Подключать только с согласия владельца.
- Примерные товары и цены служат только демонстрации и не означают текущее наличие в магазине.

## Как запустить
`python -m http.server 8080`, либо открыть `index.html` в браузере.
Публикуется в `/secret-garden/` на GitHub Pages существующего репозитория Qalta как независимая папка.

## Для продакшена
Нужны безопасный вход флориста, база данных с изоляцией магазинов, защищенное хранилище изображений, корректное отслеживание статусов и обработка персональных данных по правилам РК. Браузерный кабинет в демо доступен всем посетителям.
